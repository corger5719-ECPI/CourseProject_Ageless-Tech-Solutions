Ageless Tech Solutions Complaint Management System

Project Overview

Ageless Tech Solutions is a fictional computer and technology support business. This web-based complaint management system allows customers to report technical problems and track their progress. Technicians can review assigned complaints, add notes, and update complaint statuses. Administrators can review all complaints, assign technicians, and manage users.

This application is being developed as a class project using PHP, MySQL, HTML, CSS, and JavaScript.

Purpose

The purpose of this project is to create a secure and organized system for managing customer complaints. The application will help ensure that complaints are recorded, assigned to the correct technician, updated, and resolved.
