Ageless Tech Solutions Complaint Management System

Project Overview

Ageless Tech Solutions is a fictional computer and technology support business. This web-based complaint management system allows customers to report technical problems and track their progress. Technicians can review assigned complaints, add notes, and update complaint statuses. Administrators can review all complaints, assign technicians, and manage users.

This application is being developed as a class project using PHP, MySQL, HTML, CSS, and JavaScript.

Purpose

The purpose of this project is to create a secure and organized system for managing customer complaints. The application will help ensure that complaints are recorded, assigned to the correct technician, updated, and resolved.

PROJECT SUMMARY

# Project Name: Ageless Tech Solutions Complaint Management System

## Project Description

This project is a web-based Complaint Management System developed using PHP and MySQL. The goal of the project is to create a functional application that allows customers to submit complaints, administrators to assign complaints to technicians, and technicians to update and resolve assigned complaints.

The application uses the MVC design pattern to separate the database functions, application logic, and user interface. The project also demonstrates the use of sessions, role-based access, form validation, prepared statements, and database relationships.

## Project Tasks

- **Task 1: Set up the development environment**
  - Install and configure XAMPP
  - Start Apache and MySQL
  - Create the project folder in the XAMPP `htdocs` directory
  - Create and configure the MySQL database

- **Task 2: Plan the project**
  - Define the purpose and scope of the Complaint Management System
  - Identify the Customer, Technician, and Administrator user roles
  - Design the database tables and relationships
  - Organize the application using the MVC structure

- **Task 3: Implement core features**
  - Create customer registration and login
  - Create technician and administrator login
  - Allow customers to submit and view complaints
  - Allow administrators to view and assign complaints
  - Allow technicians to view assigned complaints
  - Allow technicians to add notes, update statuses, and resolve complaints
  - Add role-based access using PHP sessions

- **Task 4: Test the application**
  - Test valid and invalid login attempts
  - Test customer complaint submission
  - Test complaint assignment
  - Test technician complaint updates
  - Test role-based page restrictions
  - Test form validation
  - Debug file path, database connection, session, and redirect errors

- **Task 5: Document the project**
  - Create a README file
  - Create a testing document
  - Create a project retrospective
  - Document the MVC structure and project features
  - Create a screen-recorded project demonstration

- **Task 6: Finalize and submit**
  - Review and test the final project
  - Upload the project to GitHub
  - Upload the demonstration video to YouTube
  - Add the YouTube demonstration link to the GitHub project
  - Submit the completed project

## Development Process Used

- **MVC Design Pattern**: The application separates the Model, View, and Controller responsibilities.
  - The **Model** handles database queries and data.
  - The **View** displays forms, tables, and pages to the user.
  - The **Controller** processes user actions and connects the View to the Model.

- **Iterative Development**: The project was developed in stages. Features were added, tested, debugged, and improved throughout the development process.
